# 🛡️ AI Content Moderator

 Overview:
This is an AI-powered Content Moderator built using Python, Streamlit, and Hugging Face Transformers. It analyzes user-entered text and classifies it as Safe or Toxic.

 Features:
- Detects Safe and Toxic text
- Simple and interactive Streamlit interface
- Real-time text analysis
- Displays prediction confidence

## Technologies Used
- Python
- Streamlit
- Hugging Face Transformers

## How to Run

1. Install the required libraries:

```bash
pip install -r requirements.txt
```

2. Run the application:

```bash
python -m streamlit run app.py
```
